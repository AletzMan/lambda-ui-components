# 📚 Lambda UI Components

¡Bienvenido a la documentación de **Lambda UI Components**!

Esta librería ha sido diseñada para ofrecer una colección de **componentes React modernos y accesibles**, que te permitirán construir interfaces de usuario rápidas y consistentes. Cada componente está cuidadosamente elaborado para ser **altamente personalizable** y fácil de integrar en cualquier proyecto de React, sin importar su complejidad.

## 🚀 Empezando

Para comenzar, instala la librería en tu proyecto.

```bash
npm install @lambda-ui-components
```

```bash
yarn add @lambda-ui-components
```

## 📝 Uso básico

Para usar un componente, simplemente importarlo y usarlo en tu aplicación.
Cada componente viene con su propia documentación detallada y ejemplos de uso.

```tsx
import { Button } from "@lambda-ui-components";

function App() {
	return (
		<div>
			<Button>Botón</Button>
		</div>
	);
}
```
